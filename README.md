# lsdtt3_notebooks

These are some Jupyter notebooks for running basic topographic analysis on [Google Colab](https://colab.research.google.com/) using **lsdtt3** (LSDTopoTools v3) and **lsdviztools3**.

**Both packages are still in development, so these notebooks should be considered experimental.**

## Contents

- `channel_extraction/`: extracting channel networks
- `channel_cross_sections/`: tracing a mapped river (OS Open Rivers) and drawing swath cross sections of its valley from lidar
- `chi_analysis/`: chi analysis: concavity from the disorder method, channel steepness (k<sub>sn</sub>) and knickpoints
- `surface_metrics/`: computing surface metrics
- `landscape_transience/`: common analyses for checking whether a landscape is transient
- `floodplains_and_valleys/`: mapping floodplains and measuring valley widths
- `dealing_with_field_point_data/`: tying field measurements (widths, grain sizes) to the channel network: snapping GPS points to channels and adding drainage area, gradient and chi
- `lithology/`: comparing channel steepness (k<sub>sn</sub>) and hillslope metrics across the units of a geological map
- `hydrology/`: hydrological modelling of a gauged catchment with S-HYPE (daily, calibrated) and TOPMODEL (an hourly storm); its own README compares the two
- `python_binding_examples/`: using the lsdtt3 Python bindings directly from Python, without parameter files

## Notebooks

Each notebook installs everything it needs in its first few cells, so you can open any of them directly in Colab: condacolab and PyGMT from conda-forge, [lsdviztools3](https://pypi.org/project/lsdviztools3/) from PyPI, and the lsdtt3 command-line programs from the [latest lsdtt3 release](https://github.com/LSDtopotools/lsdtt3/releases/latest). The notebooks in `python_binding_examples/` install the [lsdtt3 Python package](https://pypi.org/project/lsdtt3/) from PyPI instead (Python 3.12 or later), which contains the same command-line programs as well as the Python bindings.
